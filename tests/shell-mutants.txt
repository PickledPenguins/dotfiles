#   FILE ||| FIND ||| WITH ||| TESTS

# .bats file run with bats; it must FAIL for every mutant. FIND must match
# the file exactly, indentation included: an edit to that line makes the
# mutant stale, reported apart from one that survives. Lines starting with
# # are comments.
